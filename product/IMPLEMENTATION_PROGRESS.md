## How a row moves

1. **NOT STARTED → PARTIAL:** some layer (UI, API or table) exists.
2. **PARTIAL → COMPLETED:** UI, API, table, permission check and business rules all exist, and the screen meets the brief's screen standards (search, pagination, validation, states).
3. **COMPLETED → VERIFIED:** backend tests cover the rules and permission, and the screen was driven in a browser against the running stack (later, an automated browser test).

Every move is recorded in the phase log with its commit.
